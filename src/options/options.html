UrBackup Theme+

Appearance and behaviour of the UrBackup web interface.

Theme

Dark theme only - it is applied to every UrBackup page automatically.

Features

Changes apply to open UrBackup tabs right away.

Servers

Open your UrBackup server at any address (LAN IP, DNS name, port): the extension icon appears in the toolbar on its pages and shows the state of that server - on or off. Click it once and allow access to that server; click it again to switch the theme off for that address (the page reloads into the stock UI). A server switched off stays listed below.
